# BDPedidos

Prototipo inicial de la plataforma web de Bakery Dreams.

## Ejecutar

Abrir `index.html` en el navegador. Credenciales de demostración: `admin` / `admin123`.

Incluye resumen, recepción de pedidos, finanzas y catálogo. Los datos se conservan en el almacenamiento local del navegador.

## Próxima etapa de producción

Para habilitar acceso por Internet se debe desplegar una API HTTPS con PostgreSQL, variables de entorno para credenciales y un proveedor de hosting. La app de escritorio consumirá esa misma API.
